# Security policy

This is experimental scientific software and is not yet suitable for processing
untrusted sequencing files in a security-sensitive service.

Please report crashes, memory exhaustion, decompression bombs, malformed-input
handling problems, and unsafe output-path behavior privately to the repository
owner when possible. Do not include protected genomic data or patient
information in a report or reproducer.

Version 0.1 receives best-effort security fixes but has no long-term support
commitment.
